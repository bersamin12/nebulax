# Submission assembly

`submission/nebulax/` is the prepared team folder. Before upload, rename that directory to the
team name **exactly as registered** if the registration spelling differs from `NEBULA X`.

- Keep `predictions.zip`, `demo_video.<mp4|mov>` and `app/` directly at the team-folder root.
- Record the video from `docs/demo.md`, then replace `demo_video.PLACEHOLDER.md` with the recording.
- `predictions.zip` must remain a separate ZIP containing only the four `*_predictions.csv` files
  at archive root. `predictions_baseline.zip` is supporting comparison material.
- `app/` is a self-contained copy of the Python package, models and built web UI; raw organiser
  datasets are intentionally excluded.
- The optional write-up and per-task code/model pointers live under `Optional_Items/`.

Do not submit the repository's `readingmaterials/` or any training/Test raw data.
