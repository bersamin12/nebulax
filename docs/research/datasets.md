# Datasets

Every dataset found in the W0 sweep, with its verification status. `[Rnn]` resolves to
`references.md`. Where a field could not be confirmed from the primary landing page this session it
is marked `UNVERIFIED` — verify before the result depends on it.

**Status vocabulary**
- **IN USE** — already in the plan and adapters are being written.
- **ADD** — recommended addition; the reason is stated.
- **ADD (stretch)** — worth having, only if the core is green.
- **REJECT** — with the reason.

**W1 update (14 Sep).** Three changes. (a) The three bearing **run-to-failure** sets (XJTU-SY, FEMTO,
Paderborn R2F) and **SCANIA Component X** were previously ingested for a prognostics capability the
ladder did not deliver; `model_ladder.md` §2d and §3d now supply that arm, so their status notes are
rewritten to say **which model rows consume them**. (b) A **targeted search for a bearing dataset
with a documented thermal model or an ambient temperature log** was run and **found nothing usable**
— that negative result is recorded in §3 and the bearing dataset choice is therefore **unchanged**.
(c) Three new entries were added: the TCPD change-point corpus (§4), C-MAPSS as a methodology-only
prognostics reference (§4), and Trafikverket's free detector API as a candidate source of **real
axle-box temperature measurements** (§3).

### 3b. Negative result — no bearing dataset with a documented thermal model or ambient log *(W1)*

The W1 pass searched specifically for a bearing dataset that could ground the axle-box **thermal**
model (a documented thermal model, an ambient temperature log, or a defect size plus applied load).
**Nothing usable was found, so the bearing dataset choice is unchanged.** Recording the search so it
is not repeated:

| Candidate | Why it does not close the gap |
|---|---|
| uOttawa variable-speed [R118] (our new **primary**) | The data paper states **no defect dimensions, no applied load, and there is no temperature channel at all** [R159]. It cannot ground a severity axis or a thermal model. It *can* ground the **vibration-vs-speed exponents**, because speed sweeps 13.7-28.9 Hz *within* a single 10 s record — do that instead (`rail_phm.md` §4.3.3). |
| uOttawa UORED-VAFCLS [R119] | Constant load and speed; no thermal model. Stays the constant-speed ablation. |
| FEMTO / PRONOSTIA [R143][R228] | **Carries temperature alongside vibration** — the closest available, and the reason it is prioritised among the NASA sets. But no thermal model and no ambient log. |
| PoliTo spherical roller [R139] | **Best sensor match in existence** (vibration + temperature + tacho speed + axial load on large bearings) but under a **Restricted Use Agreement** requiring written consent and forbidding redistribution. Still **REJECT** for the hackathon. |
| Paderborn KAt [R125] | Has a temperature channel, but **CC BY-NC** and no thermal model. |

opened** and are `UNVERIFIED` leads only: [R161] (paywalled) and [R162] (open access, but every fetch
route redirected) — no number from either is used anywhere.
